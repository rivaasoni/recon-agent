## How to read this

- **Sample size.** 16 cases, 2–3 per exception type. One mistake moves a type's accuracy by 33–50%, so per-type numbers point at what to investigate; they are not reliable rates.
- **One run.** LLM output varies between runs. Measuring stability needs repeat runs.
- **Synthetic, clean data.** Every exception has decisive evidence reachable through the tools. Real bank data brings partial payments, batched deposits, missing paperwork and genuinely ambiguous cases — none of which are represented here.
- **The rules did the easy work first.** Deterministic matching paired 114 of 125 bank lines, so the agent only saw genuine exceptions.
- **Cost and latency** come from the agent's own traces (tokens × list price).
