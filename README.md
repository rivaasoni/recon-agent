# Agentic Reconciliation Exceptions Assistant

> ⚠️ **All data in this project is synthetic.** No real company, bank, customer,
> or account information is used anywhere. The data is generated by a script in
> this repo and is deliberately obviously fake.

An AI agent that helps accountants resolve **bank reconciliation exceptions**.

Rule-based matching clears the easy matches between a bank statement and a
general ledger. Whatever is left — the *exceptions* — is handed to an agent that
investigates using tools, classifies the exception, explains its reasoning, and
drafts a proposed fix. **A human approves before anything is written.**

## Quickstart

```bash
# 1. Clone and enter the project
git clone <this-repo-url>
cd recon-agent

# 2. Create and activate a virtual environment (Python 3.13)
python3.13 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Configure secrets
cp .env.example .env               # then paste your Anthropic API key into .env

# 5. Verify the setup
pytest
```
